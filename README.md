# Трекер прочитанных книг

Консольное приложение для учёта прочитанных книг с оценками и статистикой.

## Как запустить

python main.py

## Возможности

- Добавление книги (автор, название, оценка 1–5, дата)
- Просмотр полного списка книг
- Средняя оценка по всем книгам
- Статистика по авторам
- Удаление книги по номеру
- Защита от дубликатов

## Пример работы

=== Трекер прочитанных книг ===
1. Добавить книгу
2. Показать все книги
3. Показать среднюю оценку
4. Статистика по авторам
5. Удалить книгу
6. Выход

## Данные

Хранятся в файле books.json в корне проекта.
